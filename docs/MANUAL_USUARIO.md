# Manual do Usuário - AgendaFlow

## 1. Login
- Acesse `/login`.
- Informe e-mail e senha.
- Se não tiver conta, use `/signup`.

## 2. Clientes
- Vá em **Clientes**.
- Preencha nome/e-mail/telefone.
- Clique em **Salvar Cliente**.

## 3. Espaços
- Vá em **Espaços**.
- Cadastre nome, localização, capacidade e status.
- Espaços inativos não aparecem para novos agendamentos.

## 4. Compromissos
- Acesse **Compromissos** > **Novo Compromisso**.
- Selecione cliente, espaço, data e horário.
- O sistema bloqueia conflitos de horário e bloqueios.

## 5. Bloquear horários
- Acesse **Bloqueios**.
- Cadastre bloqueio para todos os espaços ou específico.
- Períodos bloqueados aparecem no calendário.

## 6. Cores no calendário
- Agendado: azul
- Confirmado: verde
- Pendente: amarelo/laranja
- Cancelado: vermelho
- Concluído: cinza escuro
- Bloqueado: cinza médio

## 7. Lembretes simulados
- Em compromissos, clique em **Criar lembrete**.
- Use ação de simulação via API para marcar como enviado.

## 8. Exportar Google Agenda
- Em compromissos, clique em **Exportar Google**.
- O Google Calendar abre com evento pré-preenchido.

## 9. Configurações
- Em **Configurações**, defina horário comercial, duração padrão, intervalos e visualização padrão.
